OneStudio OS — Demo Catalog & Configurator 1.0
================================================

Что добавлено
-------------
1. Главная больше не ведёт пользователя в форму заявки:
   - главная кнопка открывает каталог демо;
   - старые CTA переведены на самостоятельный выбор;
   - карточки бизнесов открывают соответствующее демо.

2. Новый каталог /demos:
   - 8 бизнес-сценариев;
   - фильтры по направлениям;
   - отдельные действия «Посмотреть демо» и «Настроить под себя».

3. Страница каждого демо /demos/[demoSlug]:
   - вид публичного сайта;
   - вид панели управления;
   - мобильный вид;
   - список уже включённых модулей.

4. Настройщик /configure/[demoSlug]:
   - демо;
   - название и главная фраза;
   - палитра;
   - модули;
   - языки;
   - валюта, онлайн-оплата и напоминания;
   - итоговая конфигурация.

5. Конфигурация сохраняется только в браузере пользователя.
   Она не создаёт заявку и не меняет записи Supabase.

Что не менялось
---------------
- существующая админка;
- данные каталога OneStudio;
- раздел «Заявки» как дополнительный модуль;
- миграции и структура Supabase;
- переменные окружения;
- production и Vercel.

Установка
---------
cd "/Users/zina/Desktop/onestudio-os-work" && \
unzip -o "$HOME/Downloads/onestudio-demo-catalog-configurator-1.0.zip" -d . && \
rm -rf .next && \
npm run build

Локальная проверка
------------------
cd "/Users/zina/Desktop/onestudio-os-work" && npm run dev

Открыть:
- http://localhost:3000/
- http://localhost:3000/demos
- http://localhost:3000/demos/frame-house
- http://localhost:3000/configure/frame-house

Примечание
----------
Автоматическое создание нового рабочего пространства в Supabase пока не
подключено. Это отдельный следующий слой multi-tenant onboarding.
