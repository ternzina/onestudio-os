OneStudio OS — Demo Visuals 1.0

Что меняется:
- временная геометрическая фигура заменяется полноценными изображениями;
- у каждого из 8 демо появляется собственный визуал;
- смена палитры продолжает работать;
- добавлены мягкое затемнение, подпись и лёгкое увеличение изображения при наведении;
- база данных, настройки и существующие модули не затрагиваются.

Установка:

cd "/Users/zina/Desktop/onestudio-os-work" && \
unzip -o "$HOME/Downloads/onestudio-demo-visuals-1.0.zip" -d . && \
rm -rf .next && \
npm run build

После успешной сборки:

npm run dev

Проверить:
- http://localhost:3000/demos
- http://localhost:3000/demos/frame-house
- http://localhost:3000/configure/frame-house
