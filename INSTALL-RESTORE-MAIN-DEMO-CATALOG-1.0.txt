RESTORE MAIN DEMO CATALOG 1.0

Что восстанавливается в локальной базе:
- категория «Возможности»;
- единственная услуга «Посмотреть возможности»;
- описание, цена 0 EUR и длительность 60 минут как на опубликованном сайте.

Защита:
- существующие записи не удаляются и не заменяются;
- если живая услуга уже существует, миграция ничего не добавляет;
- production-деплой этим патчем не выполняется.

Установка:

cd "/Users/zina/Desktop/onestudio-os-work" && \
unzip -o "$HOME/Downloads/onestudio-restore-main-demo-catalog-1.0.zip" -d . && \
npx supabase@beta migration up

После успешной миграции:

npm run dev

Проверить:
- http://localhost:3000/admin/catalog
- http://localhost:3000/site/main

Если публичный сайт ещё не опубликован локально:
- открыть http://localhost:3000/admin/site
- нажать «Опубликовать сайт»;
- снова открыть http://localhost:3000/site/main
