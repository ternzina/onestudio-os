# MINTPAW / «ЛАПА & МЯТА» grooming demo

Отдельное визуальное демо для OneStudio OS.

## Что внутри

- новый маршрут `/demos/mintpaw-grooming`
- premium hero, услуги, комплексы и команда
- интерактивная демо-запись
- переключатель собака / кошка
- избранное для комплексов
- before / after с ползунком
- FAQ, отзыв, контакты и декоративная карта
- адаптация под desktop / tablet / mobile
- никаких новых npm-зависимостей

## Ветка

Рекомендуемая ветка:

`feature/premium-grooming-demo-1.0`

## Проверка

После копирования файлов:

```bash
npm run build
npm run dev
```

Открыть:

`http://localhost:3000/demos/mintpaw-grooming`

Примечание: изображения сейчас подключены по прямым URL Unsplash, чтобы ветка оставалась маленькой. После визуального утверждения их лучше заменить локальными оригинальными WebP-ассетами и уже затем подключать шаблон к Premium Template Package / редактору.
