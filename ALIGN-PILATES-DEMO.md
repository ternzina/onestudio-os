# ALIGN Pilates Studio demo 1.0

Visual demo route for OneStudio OS.

- Route: `/demos/align-pilates-studio`
- Isolated CSS module, no global CSS changes
- Responsive desktop/tablet/mobile layout
- Sections: promo, hero, formats, benefits, schedule, trainers, trial booking, memberships, studio gallery, testimonial, FAQ, contacts and footer
- Demo images are prepared from the provided visual reference so the first implementation can be reviewed without external image dependencies.
- This package intentionally does not register ALIGN as a customer-creatable premium template yet. Editor/template-package integration should be a separate step after the visual demo is approved.
