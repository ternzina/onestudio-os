PUBLIC CATALOG + REQUESTS LINK 1.0

Что меняется:
- главная страница ведёт в живой каталог и публичную форму /request/main;
- карточки услуг на /site/[businessSlug] открывают форму с заполненной темой;
- тема сохраняется в public_requests и отображается в /admin/requests;
- раздел «Заявки» доступен в верхней навигации админки;
- кнопки боковой панели открывают сайт и бронирование текущего рабочего пространства.

Миграций базы данных в этом патче нет.

Установка:

cd "/Users/zina/Desktop/onestudio-os-work" && \
unzip -o "$HOME/Downloads/onestudio-public-catalog-requests-link-patch-1.0.zip" -d . && \
rm -rf .next && \
npm run build

После успешной сборки запустить локально:

npm run dev

Проверить:
- http://localhost:3000
- http://localhost:3000/site/main
- http://localhost:3000/request/main
- http://localhost:3000/admin/requests

Production-деплой выполнять только после локальной проверки:

vercel --prod
