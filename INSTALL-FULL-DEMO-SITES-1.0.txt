OneStudio OS — Full Demo Sites 1.0

Добавлено:
- полноценные секции сайта во всех 8 демо;
- индивидуальные услуги и предложения для каждого бизнеса;
- блок преимуществ и характерного процесса;
- финальная кнопка действия;
- продолжение страницы в мобильном предпросмотре.

Установка:
1. Распаковать архив в корень onestudio-os-work с заменой файлов.
2. Удалить папку .next.
3. Выполнить npm run build.
4. Запустить npm run dev и открыть /demos.

База данных, переменные окружения и production не изменяются.
