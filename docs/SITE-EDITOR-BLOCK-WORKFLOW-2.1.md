# Site Editor Block Workflow 2.1.1

## Scope

- Native drag-and-drop for home-page sections and custom blocks.
- Native drag-and-drop for custom blocks on additional pages.
- Accessible up/down controls remain available.
- Duplicate selected custom block.
- Undo and redo editor changes.
- Unsaved-change indicator and leave-page protection.
- Explicit, high-contrast controls for opening and closing the blocks menu.
- A visible client-dashboard link inside the editor toolbar.
- High-contrast button text throughout the visual editor.

## 2.1.1 usability correction

The duplicate action is now visible in the editor toolbar instead of being discoverable only at the bottom of the settings panel. The blocks-menu toggle and dashboard return action are always clearly labelled. Light controls now use explicit dark text.

## Data and dependencies

No database migration is required.
No new package dependency is required.
