# Site Editor Heading Controls 2.6.3

- Heading font/size/weight controls now live directly beside the heading field.
- Built-in sections and Hero use the same control placement.
- Legacy vague small/medium/large heading presets are replaced in the editor by explicit pixel sizes.
- Existing saved small/medium/large/display values are normalized to 32/48/72/104 px.
- The old Hero mobile-size selector is kept in stored content for compatibility but removed from the editor UI.
- Custom block and custom page titles use the same controls and persistence contract.
- The safe public runtime applies the same normalized typography in editor preview, Standard, GLOSS and custom-page rendering.
