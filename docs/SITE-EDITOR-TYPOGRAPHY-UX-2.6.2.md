# Site Editor Typography & UX 2.6.2

- The separate Site Design mode and toolbar button are removed; the selected block always owns the right inspector.
- The editor toolbar is sticky and wraps instead of disappearing off-screen.
- Built-in section headings, including Hero, custom blocks and custom pages use one local typography model: font, numeric px size, weight, italic, underline, alignment, color, line height and letter spacing.
- “Использовать стиль сайта” removes the sparse local override and restores Global Design System inheritance.
- Heading overrides are sparse and preserve template appearance until explicitly changed.
- Existing Rich Text Editor 2.6.1 behavior remains unchanged.
