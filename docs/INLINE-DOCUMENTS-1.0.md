# Inline Documents 1.0

Inline Documents brings generated documents into the daily client and booking workflows.

## Client card

The client card lists all generated documents linked to the selected client, including documents created from any of that client's bookings.

## Booking card

The booking card lists documents linked to the selected booking.

## Available actions

- View the immutable rendered snapshot.
- Print or save the snapshot as PDF.
- Send or resend the document by email through the existing document delivery route.
- Open the full Documents screen to create another document.

## Delivery states

The card distinguishes final, sent, failed and void documents using `sent_at`, `delivery_error` and the document status.
