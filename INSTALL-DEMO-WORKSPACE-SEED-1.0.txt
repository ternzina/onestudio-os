OneStudio OS — Demo Workspace Seed 1.0

Состав:
- supabase/migrations/20260729120000_demo_workspace_seed_1_0.sql

Что делает:
- добавляет стартовый ресурс и рабочее расписание для нового демо-сайта;
- создаёт три редактируемые стартовые услуги по выбранной нише;
- связывает услуги с ресурсом для онлайн-записи;
- наполняет черновик публичного сайта текстами выбранного демо;
- обрабатывает уже созданные, но ещё пустые демо-пространства;
- не публикует сайт автоматически и не заменяет существующие услуги клиента.

Установка:
1. Распаковать архив в корень onestudio-os-work.
2. Проверить список миграций.
3. Применить миграцию обычным supabase db push без reset.
