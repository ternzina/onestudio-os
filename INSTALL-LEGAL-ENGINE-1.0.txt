OneStudio OS Legal Engine 1.0

1) Сделайте резервную копию текущего проекта.
2) Распакуйте этот архив в корень /Users/zina/Desktop/onestudio-os-work с заменой файлов.
3) В Terminal:

cd "/Users/zina/Desktop/onestudio-os-work" && \
npx supabase@beta db reset && \
npx supabase@beta test db && \
npm run build

4) Если всё PASS, проверьте remote dry-run:

cd "/Users/zina/Desktop/onestudio-os-work" && \
npx supabase@beta db push --linked --dry-run

5) После подтверждения примените migration:

cd "/Users/zina/Desktop/onestudio-os-work" && \
npx supabase@beta db push --linked

6) Запустите локально и откройте:
http://localhost:3000/admin/legal
или ваш обычный локальный порт.

7) Нажмите Create Legal Engine 1.0, заполните отсутствующий адрес, сохраните реквизиты, проверьте и опубликуйте документы.

8) Публичная украинская оферта:
https://onestudioos.com/legal/uk/public-offer

Важно: тексты являются рабочими юридическими черновиками под OneStudio OS. Перед большим оборотом, международными продажами или спорной моделью лицензирования желательна проверка украинским юристом.
